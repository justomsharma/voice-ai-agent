# 01_audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record the mic as raw 16-bit PCM in 20 ms blocks, save it, then inspect and plot it so that 8 / 16 / 48 kHz can be compared.

**Architecture:** There are four small modules in `01_audio/`. `audio_format` does the pure math, `wav_io` does file I/O, `inspect_audio` does stats and plots, and `record` does mic capture. Only `record` touches the microphone, so everything else can be tested with synthetic sine waves.

**Tech Stack:** Python 3.14, sounddevice, numpy, matplotlib, pytest, stdlib `wave`.

**Spec:** `docs/superpowers/specs/2026-10-04-01-audio-design.md`

## Global Constraints

- No LiveKit, Pipecat, STT, LLM or TTS.
- Every important implementation decision gets an explaining comment (the "why", not the "what").
- Samples are always `int16`, shaped `(frames, channels)`.
- The file is named `inspect_audio.py`, never `inspect.py` (that name shadows the stdlib module).
- Windows and `venv`: `python -m venv .venv`, then `.venv/Scripts/python -m pytest`.

## Review Focus

1. **Silent audio** (all zeros): `log10(0)` gives -inf. Stats must print `-inf dBFS`, not crash or warn. Tested in Task 4.
2. **Stereo input** (`--channels 2`): stats and plots must handle shape `(N, 2)`. Tested in Task 4.
3. **Recording shorter than the 20 ms zoom window**: the zoom must clamp to the file length. Tested in Task 4.
4. **`.raw` file without `--rate`**: there's no header, so the format is unknown. The CLI must exit with a clear message. Tested in Task 4.
5. **Device doesn't support the requested rate**: a clear error plus a `--list-devices` hint. Checked by hand in Task 5.

### Task 3: `wav_io.py`

**Consumes:** `AudioFormat`.
**Produces:** `write_wav(path, fmt, samples) -> None`, `write_raw(path, samples) -> None`, `read_wav(path) -> tuple[AudioFormat, np.ndarray]`, `read_raw(path, fmt) -> np.ndarray`. Reads return `int16` arrays shaped `(frames, channels)`. `read_wav` raises `ValueError` if the sample width isn't 2. Writers create parent directories.

- [ ] Write `01_audio/tests/test_wav_io.py`:
```python
import wave, numpy as np, pytest
from audio_format import AudioFormat
from wav_io import write_wav, read_wav, write_raw, read_raw

def _tone(fmt, n=1600):
    return (np.arange(n * fmt.channels, dtype=np.int16) % 1000).reshape(n, fmt.channels)

@pytest.mark.parametrize("fmt", [AudioFormat(16000, 1), AudioFormat(48000, 2)])
def test_wav_roundtrip(tmp_path, fmt):
    x = _tone(fmt); p = tmp_path / "a.wav"
    write_wav(p, fmt, x)
    fmt2, y = read_wav(p)
    assert fmt2 == fmt and np.array_equal(x, y)
    assert p.stat().st_size == 44 + x.nbytes   # header + raw PCM

def test_raw_is_headerless(tmp_path):
    fmt = AudioFormat(8000, 1); x = _tone(fmt); p = tmp_path / "a.raw"
    write_raw(p, x)
    assert p.stat().st_size == x.nbytes
    assert np.array_equal(read_raw(p, fmt), x)

def test_rejects_8bit_wav(tmp_path):
    p = tmp_path / "8bit.wav"
    with wave.open(str(p), "wb") as w:
        w.setnchannels(1); w.setsampwidth(1); w.setframerate(8000); w.writeframes(b"\x80" * 10)
    with pytest.raises(ValueError):
        read_wav(p)
```

### Task 4: `inspect_audio.py`

**Consumes:** `AudioFormat`, `read_wav`, `read_raw`.
**Produces:**
- `compute_stats(fmt, samples, file_bytes) -> dict` with keys `sample_rate, channels, bit_depth, frames, total_samples, duration_s, min, max, peak_dbfs, rms_dbfs, clipped, data_bytes, file_bytes, header_bytes`. A silent file gives `-inf` dBFS, with no numpy warning.
- `magnitude_spectrum(fmt, samples) -> (freqs_hz, dbfs)`, using channel 0 and a Hann window.
- `zoom_window(fmt, samples, ms=20, center=True) -> np.ndarray`, clamped to the file length.
- `plot(files: list[tuple[str, AudioFormat, np.ndarray]]) -> None`: one row per file with three panels (full waveform, 20 ms zoom with dots, spectrum on a log-frequency axis with a Nyquist line).
- `main(argv=None) -> int`. The CLI takes `paths...`, `--rate`, `--channels`, `--no-plot`. A `.raw` file without `--rate` exits with code 2 and a message.

- [ ] Write `01_audio/tests/test_inspect_audio.py`:
```python
import numpy as np, pytest
from audio_format import AudioFormat
from inspect_audio import compute_stats, magnitude_spectrum, zoom_window, main
from wav_io import write_wav

def sine(fmt, hz=440, secs=1.0, amp=32767):
    t = np.arange(int(fmt.sample_rate * secs)) / fmt.sample_rate
    x = (amp * np.sin(2 * np.pi * hz * t)).astype(np.int16)
    return np.repeat(x[:, None], fmt.channels, axis=1)

def test_full_scale_sine_stats():
    fmt = AudioFormat(16000, 1); s = compute_stats(fmt, sine(fmt), 44 + 32000)
    assert s["frames"] == 16000 and s["duration_s"] == 1.0
    assert s["peak_dbfs"] == pytest.approx(0, abs=0.1)
    assert s["rms_dbfs"] == pytest.approx(-3.01, abs=0.1)
    assert s["header_bytes"] == 44

def test_silence_is_minus_inf(recwarn):
    fmt = AudioFormat(8000, 1); s = compute_stats(fmt, np.zeros((800, 1), np.int16), 1644)
    assert s["rms_dbfs"] == -np.inf and s["peak_dbfs"] == -np.inf
    assert len(recwarn) == 0

def test_stereo_counts():
    fmt = AudioFormat(48000, 2); s = compute_stats(fmt, sine(fmt, secs=0.5), 44 + 96000)
    assert (s["frames"], s["total_samples"]) == (24000, 48000)

@pytest.mark.parametrize("rate", [8000, 16000, 48000])
def test_spectrum_peak_at_tone(rate):
    fmt = AudioFormat(rate, 1); f, db = magnitude_spectrum(fmt, sine(fmt, hz=1000))
    assert abs(f[np.argmax(db)] - 1000) < 5 and f[-1] == fmt.nyquist_hz

def test_zoom_clamps_short_file():
    fmt = AudioFormat(16000, 1)
    assert len(zoom_window(fmt, sine(fmt, secs=0.005))) == 80   # 5 ms < 20 ms
    assert len(zoom_window(fmt, sine(fmt))) == 320

def test_raw_without_rate_exits_2(tmp_path):
    p = tmp_path / "a.raw"; p.write_bytes(b"\0\0" * 10)
    assert main([str(p), "--no-plot"]) == 2

def test_cli_wav_no_plot(tmp_path, capsys):
    fmt = AudioFormat(16000, 1); p = tmp_path / "a.wav"; write_wav(p, fmt, sine(fmt))
    assert main([str(p), "--no-plot"]) == 0
    assert "16000" in capsys.readouterr().out
```

### Task 5: `record.py`

**Consumes:** `AudioFormat`, `write_wav`, `write_raw`.
**Produces:** a CLI taking `--rate 16000 --channels 1 --seconds 3 --block-ms 20 --device --name take --list-devices`. It writes `01_audio/recordings/<name>_<rate>hz.wav` and `.raw`.

Implementation notes (each one gets a "why" comment in the code):
- `sd.check_input_settings(device, channels, 'int16', samplerate=rate)` runs first. A `PortAudioError` produces a clear message, a `--list-devices` hint, and exit code 1.
- Print the device name and its `default_samplerate` (its native rate).
- The callback does only `q.put((indata.copy(), time.inputBufferAdcTime, bool(status.input_overflow)))`.
- The main loop does `q.get(timeout=1)` and logs `block# | frames | ms | delay_ms = (stream.time - adc)*1000`. It stops once enough frames have arrived, then concatenates and trims to `rate*seconds`.
- `KeyboardInterrupt`: save what was captured. At the end, print the overflow count.
