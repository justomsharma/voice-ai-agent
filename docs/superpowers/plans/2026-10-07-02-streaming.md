# 02_streaming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stream 20 ms PCM frames from mic (or a .wav file) over UDP to a receiver with a jitter buffer that plays them, while artificially adding delay, jitter, and loss.

**Architecture:** Three pure modules hold the logic: `packet` (wire format), `netsim` (drop/delay decisions plus a timed send queue), and `jitter_buffer` (reorder, pre-roll, fixed playout clock). Two scripts do the I/O: `sender.py` (mic/wav → UDP) and `receiver.py` (UDP → speaker). Only the scripts touch audio devices or sockets, so the logic is testable without either.

**Tech Stack:** Python 3.14, sounddevice, numpy, stdlib `socket`/`struct`/`threading`, pytest. Reuses `01_audio/audio_format.py` and `01_audio/wav_io.py`.

**Spec:** `docs/superpowers/specs/2026-10-07-02-streaming-design.md`

## Global Constraints

- No LiveKit, Pipecat, Twilio, STT, LLM, TTS.
- Teaching comments explain every "why". Samples are int16, shaped `(frames, channels)`.
- Localhost UDP, default `127.0.0.1:5005`. Packet header: `!IQIH` (18 bytes).
- Scripts reach 01_audio via `sys.path.insert(0, <repo>/01_audio)`. Tests use pyproject's `pythonpath`.
- `02_streaming/tests/` has **no** `__init__.py`: 01_audio already has a `tests` package, and a second one would collide.
- Windows `.venv`: run with `.venv/Scripts/python`.

## Review Focus

1. **The WAV length isn't a whole number of frames.** Pad the last frame with zeros so every packet is the same size. Test: `test_split_frames_pads_last` (Task 4).
2. **`--buffer-ms` isn't a multiple of the frame size** (for example 50 ms with 20 ms frames). Round up to 3 frames, never down. Test: `test_frames_for_ms_rounds_up` (Task 3).
3. **The sender runs with no receiver listening.** UDP doesn't care, and the sender must not crash. Windows can raise `ConnectionResetError` on a UDP socket after an ICMP "port unreachable" comes back. `send()` catches `OSError` and counts it. Checked by hand in Task 6.
4. **The stream ends.** The playout clock keeps ticking after the last packet, and those ticks must not count as losses. Test: `test_end_of_stream_not_missed` (Task 3).
5. **Ctrl+C on the receiver before any packet arrives** must exit cleanly with no traceback and no empty WAV. Checked by hand in Task 6.

```python
import struct
from dataclasses import dataclass

_HEADER = struct.Struct("!IQIH")
HEADER_SIZE = _HEADER.size

@dataclass(frozen=True)
class Packet:
    seq: int
    send_time_ns: int
    sample_rate: int
    channels: int
    pcm: bytes

def encode(p: Packet) -> bytes:
    return _HEADER.pack(p.seq, p.send_time_ns, p.sample_rate, p.channels) + p.pcm

def decode(data: bytes) -> Packet:
    if len(data) < HEADER_SIZE:
        raise ValueError(f"packet is {len(data)} bytes, shorter than the {HEADER_SIZE}-byte header")
    seq, t, rate, ch = _HEADER.unpack_from(data)
    return Packet(seq, t, rate, ch, data[HEADER_SIZE:])
```

- [ ] Implement:
```python
import heapq, itertools, random, threading, time

class NetSim:
    def __init__(self, delay_ms=0.0, jitter_ms=0.0, loss=0.0, seed=None):
        if not 0.0 <= loss <= 1.0: raise ValueError(f"loss must be in [0, 1], got {loss}")
        if delay_ms < 0 or jitter_ms < 0: raise ValueError("delay_ms and jitter_ms must be >= 0")
        self.delay_ms, self.jitter_ms, self.loss = delay_ms, jitter_ms, loss
        self._rng = random.Random(seed)
    def decide(self):
        if self._rng.random() < self.loss: return None
        ms = self.delay_ms + self._rng.uniform(-self.jitter_ms, self.jitter_ms)
        return max(0.0, ms) / 1000

class DelayLine:
    def __init__(self, send_fn):
        self._send = send_fn
        self._heap = []
        self._tie = itertools.count()
        self._lock = threading.Lock()
        self._closing = False
        self._thread = threading.Thread(target=self._run, daemon=True)
        self._thread.start()
    def put(self, delay_s, data):
        with self._lock:
            heapq.heappush(self._heap, (time.perf_counter() + delay_s, next(self._tie), data))
    def close(self):
        with self._lock: self._closing = True
        self._thread.join()
    def _run(self):
        while True:
            data = None
            with self._lock:
                if self._heap and self._heap[0][0] <= time.perf_counter():
                    data = heapq.heappop(self._heap)[2]
                elif not self._heap and self._closing:
                    return
            if data is not None: self._send(data)
            else: time.sleep(0.001)
```
  Comments should explain: uniform jitter means reordering, why the delay is clamped at 0, why the heap needs a tie-breaker, why we poll every 1 ms instead of using `Condition.wait` (on Windows, timed waits can round up to the ~15.6 ms system tick, while `time.sleep` uses a high-resolution timer in 3.11+), and why we send outside the lock.

```python
import math
from dataclasses import dataclass

def frames_for_ms(buffer_ms, frame_ms):
    return math.ceil(round(buffer_ms / frame_ms, 6))

@dataclass(frozen=True)
class Frame:
    seq: int
    payload: bytes | None
    send_time_ns: int | None

class JitterBuffer:
    def __init__(self, target_frames):
        if target_frames < 0: raise ValueError(...)
        self.target_frames = target_frames
        self._held = {}                 # seq -> (payload, send_time_ns)
        self._next_seq = None           # None = pre-rolling
        self.highest_seq = None
        self._missed = []
        self.received = self.late = self.duplicate = self.reordered = self.played = 0
    started = property(lambda self: self._next_seq is not None)
    depth = property(lambda self: len(self._held))
    def push(self, seq, payload, send_time_ns):
        if self._next_seq is not None and seq < self._next_seq:
            self.late += 1; return "late"
        if seq in self._held:
            self.duplicate += 1; return "duplicate"
        self.received += 1
        if self.highest_seq is not None and seq < self.highest_seq: self.reordered += 1
        self.highest_seq = seq if self.highest_seq is None else max(self.highest_seq, seq)
        self._held[seq] = (payload, send_time_ns)
        if self._next_seq is None and len(self._held) >= max(1, self.target_frames):
            self._next_seq = min(self._held)
        return "ok"
    def pop(self):
        if self._next_seq is None: return None
        seq = self._next_seq; self._next_seq += 1
        item = self._held.pop(seq, None)
        if item is None:
            self._missed.append(seq); return Frame(seq, None, None)
        self.played += 1
        return Frame(seq, *item)
    def missed_count(self):
        if self.highest_seq is None: return 0
        return sum(1 for s in self._missed if s <= self.highest_seq)
```
  The docstring explains the fixed jitter buffer (pre-roll, then one frame per tick no matter what) and the trade-off between latency and late frames.
