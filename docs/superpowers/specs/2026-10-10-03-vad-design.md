# 03_vad — Design Spec

Date: 2026-10-10
Status: Approved in conversation

## Purpose

Teach the program to hear *when* someone is speaking. Cut audio into 20 ms
frames, measure each frame's loudness (RMS in dBFS), and turn that into
clean SPEECH / SILENCE segments that don't flicker. Then show where a pure
loudness detector fails (noise, quiet words), which is why real agents use
an ML model.

VAD answers "is there speech sound right now?", not "is the person done?".
That second question is turn detection (Stage 08).

## Constraints

- No LiveKit, Pipecat, Silero or any model. Python + numpy (+ sounddevice
  for the mic, matplotlib for `--plot`), all already in requirements.txt.
- Same style as 01/02: teaching comments, int16 PCM, pure logic separate
  from I/O, tests without a mic. Reuse `01_audio/wav_io.py` + `audio_format.py`.

## How the pros do it (checked 2026-10-10)

| | Silero `get_speech_timestamps` | LiveKit Silero plugin | Pipecat `VADParams` |
|---|---|---|---|
| Start threshold | 0.5 | 0.5 | 0.7 |
| Stop threshold | start − 0.15 | start − 0.15 | same |
| Min speech | 250 ms | 50 ms | 200 ms (`start_secs`) |
| Min silence | 100 ms | 550 ms | 200 ms (`stop_secs`) |
| Padding | 30 ms both sides | 500 ms before | — |

Lessons we copy: **two thresholds** (start louder than stop = hysteresis),
**min speech**, **min silence**, **padding**, and Pipecat's 4-state machine
`QUIET → STARTING → SPEAKING → STOPPING`. Pipecat also requires a minimum
*volume* on top of the model, so energy checks are still used in production,
just not alone.

## Components

### `energy.py`
`frame_dbfs(frame) -> float`: RMS of an int16 frame (all channels), in
dBFS (0 = full scale). Digital silence → -120 floor instead of -inf.

### `vad.py`
`VadConfig(frame_ms=20, start_db=-40, stop_db=-45, min_speech_ms=200,
min_silence_ms=500, pad_ms=100)`. Rejects `stop_db > start_db` and
non-positive frame/durations.

`EnergyVad(config)`, fed one frame's dB at a time (streaming, works for
mic and file alike). `push(db) -> list[Segment]` returns any segment that
just finished. `flush()` closes an open segment at end of audio.
- QUIET: frame ≥ `start_db` → STARTING.
- STARTING: needs `min_speech_ms` of frames ≥ `stop_db` in a row → SPEAKING;
  a drop below `stop_db` → back to QUIET (it was a click / door slam).
- SPEAKING: frame < `stop_db` → STOPPING.
- STOPPING: `min_silence_ms` below `stop_db` → segment ends, QUIET;
  any frame ≥ `stop_db` → back to SPEAKING (it was just a pause).
- `Segment(start_s, end_s)`: first loud frame − `pad_ms` to last loud
  frame + `pad_ms`, clamped to ≥ 0. Padding saves quiet word edges
  ("s", "f", "h" have little energy).
- Also records the per-frame raw decision (`db ≥ start_db`) so the CLI can
  show raw vs cleaned side by side.

### `detect.py`
`python 03_vad/detect.py --wav FILE` or `python 03_vad/detect.py` (mic,
`--seconds 10`, `--device`). Flags map 1:1 to `VadConfig`
(`--start-db --stop-db --min-speech-ms --min-silence-ms --pad-ms --frame-ms`).
- `--noise DB`: mix white noise at that RMS level (seeded) into the audio
  before detection, so you can watch false positives appear.
- Prints: settings, segment list (`0.84s – 2.10s  speech`), and two
  timelines, one char per 100 ms: `raw` (flickers) vs `vad` (clean).
- Mic mode also prints `SPEECH START / END` live as it happens.
- `--plot`: waveform + per-frame dB curve with the two threshold lines and
  shaded segments: the tool for tuning thresholds.
- `--out PATH`: write only the speech parts to a WAV, so you can *hear*
  what got kept or chopped.

## Error handling
Bad config / unreadable WAV / bad mic → one clear `error:` line, exit 1.
Stereo is fine (RMS over all channels).

## Testing (pytest, synthetic signals, no mic)
- energy: silence → floor; full-scale sine ≈ -3 dB; known level round-trips.
- vad: silence → no segments; 1 s tone → one segment with padding; 60 ms
  burst → nothing (shorter than min speech); tone–300 ms gap–tone → one
  segment; tone–800 ms gap–tone → two; hysteresis: level between stop and
  start keeps SPEAKING going but can't start it; flush closes open speech.
- detect: `--noise` raises false positives on a silent file; `--out` keeps
  only speech samples.

Manual: README experiments on your own Stage 01 recording (threshold too
high/low, `--noise`, `--pad-ms 0` chops word edges, pause mid-sentence).

## Out of scope
ML VAD (Silero comparison is a later step), adaptive noise-floor
threshold (mentioned in README only), turn detection (Stage 08), feeding
STT (Stage 04).
